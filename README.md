# 面向规约开发（Spec-Oriented Development，SOD）

> 先有规约，再写代码；实现回指规约，验证对照规约，经验反哺规约。

一套让 AI 从「一次聪明」变成「稳定可靠」的方法论。核心隐喻：**规约是罗盘（可生长），不是引擎（先完美再照做）**。

## 这是什么

「面向规约开发」回答一个核心问题：**如何让 AI 的「一次性聪明」变成「可复用、可跨会话、可换模型依然稳定」的约束。**

它沉淀自 daodejing-kb（慧惠道德经）项目的真实实践，包含方法论正文、两个反向案例（实现偏离 / 依据偏离）、四套可复用模板，以及一套公众号自动化脚本。

## 快速开始

1. 先读 [docs/README.md](docs/README.md) 了解七份文档导航。
2. 从 [01-面向规约开发方法论.md](docs/01-面向规约开发方法论.md) 入门。
3. 想直接套用到新项目：读 [05-面向规约-可复用模板.md](docs/05-面向规约-可复用模板.md)。

## 核心概念

- **规约四层**：宪法 → 设计文档 → 工程约定（AGENTS）→ 项目记忆
- **五步闭环**：需求即转译 → 实现即对齐 → 验证即自检 → 经验即固化 → 偏差即教材
